# Phase 2: Brand strategy

Where the fee is earned. Everything downstream executes decisions made here, so a generic Phase 2 cannot be rescued by any amount of Phase 4 polish.

Output: `brand/BRAND.md`, in the structure below.

---

## 1. Positioning

"For [audience], [product] is the [category] that [differentiator], because [reason to believe]."

Then sharpen until it is **false of the competitors named at intake**. If swapping in a competitor's name still reads true, the differentiator is not found yet.

## 2. Tone of voice

A do/don't table, five rows minimum, each specific to this brand. "Do: be clear. Don't: be confusing." is true of every brand and counts for nothing. A row should let a copywriter who has never met the founder write a sentence the founder would sign.

| Do | Don't |
|---|---|
| | |

## 3. Narrative

**Problem:** what the founder saw that was broken.
**Belief:** the conviction that others might not share, stated as a conviction.
**Product:** how it embodies the belief, not what features it has.
**Proof:** why anyone should believe this is more than positioning.

This becomes the chapter order of the site. If the four beats do not have to happen in this order for the belief to land, they are not a narrative yet.

## 4. The motif

One recurring device the identity is built from. Derived from the **belief**, never the category. "Analytics" yields a chart, which any competitor could use; "teams drown in metrics that predict nothing" yields a noise-to-signal waveform, which only this brand can.

Write the motif and the one sentence explaining why it belongs to this brand and no competitor. Then name at least three forms it will take on the page, each doing structural work, never the same icon repeated. Full rules: `taste-frontend/SKILL.md`, the Identity Mandate.

The mark in `brand/logo/` will be generated from this motif. The mark and the page must read as one organism.

## 5. Visual register

Premium-minimalist, or technical/generative. Criteria for each, and when the second is wrong: `taste-frontend/references/visual-registers.md`. Choose, and write the reason. Do not let it fall out of token choices later.

## 6. Closest corpus reference

From `taste-frontend/references/reference-corpus.md`, name the site this brief is closest to in **kind** (scroll-film, warm product, catalogue, playable, tool, software with no photogenic subject) and write exactly what to take from it. "Cinematic like noireternel" and "warm like agrumeafarm" are different builds.

## 7. The 3D decision

Does the brief warrant an object built in Blender? Yes only when an object with no photograph is central to the identity: an extruded mark, an abstract brand form, something the visitor should turn. **Never to stand in for a missing product**, and never because 3D is impressive. None of the corpus references use 3D that way. Write yes or no, and why. Criteria: `taste-frontend/references/blender-pipeline.md`.

## 8. Naming and tagline

Only if flagged generic in the audit. Options that connect to the narrative, not words that sound nice.

---

## What does not happen in this phase

No image generation, no logo attempts, no palette picking. Those are Phase 3, driven by this document. A logo generated before the motif exists is decoration; a palette picked before the register is chosen is a default.
